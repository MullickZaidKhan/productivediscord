Wolvo CSRF Attack Test

This page attempts a cross-origin PUT request to change the authenticated user's name. Do not use against any app you do not own or have permission to test.

PUT http://localhost:5000/api/v1/usersetting/update-name
Middleware: verifyJwt
Target: Authenticated user's name field
This test submits a cross-site request using your current browser session cookies/tokens. Verify the outcome in your Wolvo app tab and server logs. A "200 OK" or success message while on a different origin indicates the route may be vulnerable to CSRF. 
Status: Ready — open this page while logged into your Wolvo app.
